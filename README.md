<strong>Description</strong>

A simple catalog, allowing insertion, deleting, searching and 
overall visualization of endangered species. Its application was made utilizing a mix of a quaternary 
tree and multiple AVL trees.

Each species is firstly introduced to a sorting based on its primal biological characteristics, initially 
deciding if they are vertebrates or invertebrates, and then placing them into either terrestrial, 
aquatic, flying or amphibious. <br></br>


<strong>Utilization</strong>

After downloading and opening the application file with 
your Code Editor or Java Virtual Machine of choice, executing the code will present you with a menu in Por
tuguese revealing all available options. 

Navigation of the menu and insertion of species is done with numbers, and they will usually be notated either 
in topics (such as: “4. Busca”) or in parenthesis (such as: “vertebrados(1)”).
Resulting from this implementation, a catalog that separates species into 8 different classifications while 
maintaining alphabetical order and search efficiency automatically as insertion and deletion is applied, with 
dedicated error prevention in each function
